# zerosum-theme

Custom CSS themes for ZeroSum by Juulz, applied with the
[Magic CSS](https://github.com/webextensions/live-css-editor) browser extension.

To use a theme, paste a file from [`dist/`](dist) into Magic CSS in SCSS mode.
To change a theme, describe it in a Cursor chat on this repo and review the
pull request it opens; see [NOTES.md](NOTES.md) for that workflow, editing by
hand, and making a new theme. Agent conventions are in [AGENTS.md](AGENTS.md).
